# 明日方舟桌宠 4.0 皮肤开发与扩展契约规范

欢迎使用明日方舟桌宠 4.0 工业级皮肤规范。

在 4.0 纯净架构中，所有的角色动画均基于 Spine 骨骼管线烘焙的高清等比切片与统一的 `skin.json` 元数据驱动。

---

## 1. 皮肤目录结构

每一个皮肤文件夹置于 `skins/<skin_id>/` 目录下，结构必须保持如下标准：

```text
skins/
└── <skin_id>/
    ├── skin.json             # 皮肤元数据配置文件 (必须)
    ├── preview.png           # 皮肤预览图 (可选，用于菜单展示)
    └── actions/              # 动作帧图像目录 (必须)
        ├── idle/             # 待机动作
        │   ├── idle_00.png
        │   └── ...
        ├── walk/             # 漫步动作
        ├── drag/             # 提溜悬空扑腾动作
        ├── sit/              # 坐下动作
        ├── sleep/            # 熟睡动作
        ├── headpat/          # 摸头互动
        ├── trans_sit/        # 站立 -> 坐下过渡切片
        ├── trans_sleep/      # 坐下 -> 睡觉过渡切片
        ├── fall/             # 自由落体下坠动作
        └── land/             # 触地受力缓冲站稳
```

---

## 2. `skin.json` 元数据契约

`skin.json` 必须包含以下字段：

```json
{
  "name": "skin_id",
  "title": "皮肤中文展示名",
  "author": "创作者名字",
  "version": "4.1.0",
  "description": "皮肤简述",
  "fps": 30,
  "width": 360,
  "height": 480,
  "anchor_y": 466,
  "default_scale": 1.0,
  "actions": {
    "<action_key>": {
      "name": "动作展示名",
      "type": "loop",         // "loop" (循环) | "once" (单次播放) | "transition" (状态切换切片)
      "duration": 2.0,        // 动画单周期秒数
      "frames_count": 60,     // 帧图片总数
      "fps": 30,              // 采样帧率
      "loop": true,           // 是否循环
      "desc": "动作说明"
    }
  }
}
```

### 必须提供的基准动作清单 (Core Action Keys)
1. `idle`: 核心待机深呼吸；
2. `walk`: 完整步态周期漫步；
3. `drag`: 鼠标长按提溜悬空扑腾；
4. `sit`: 坐下休息；
5. `sleep`: 熟睡；
6. `headpat`: 抚摸互动；
7. `trans_sit`: 站立到坐下的过渡切片；
8. `trans_sleep`: 坐下到入睡的过渡切片；
9. `fall`: 半空脱手下落；
10. `land`: 接触地面受力缓冲。

---

## 3. 尺寸与度量衡规范（防切边与防跳变原则）

1. **统一画布**：标准分辨率统一为 `360 x 480`，地面吸附锚点 `anchor_y = 466`。
2. **统一 Scale**：全套动作角色骨骼身高缩放比例必须严格统一在 `0.85` 左右，严禁不同动作忽大忽小（如 0.48 与 0.95 混用），以杜绝落地或切换时出现跳变缩小。
3. **安全边界**：四周保留至少 15~20px 的透明安全内衬，确保角色动作挥动、风衣扬起、尾巴摇摆时图像边缘零裁切（不接触四周边框）。
